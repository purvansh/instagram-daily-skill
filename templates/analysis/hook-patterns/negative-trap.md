# Hook Pattern — Negative Trap (Double-Bind Callout)

**Reference example:** "If quitting your job isn't an option, but staying another year feels impossible, this page is for you" — `@ameliagonzamonte` (95 comments, 9 shares, **4,037 saves**).

## The pattern

```
IF [option A is impossible]
BUT [option B is also unbearable]
→ this is for you
```

Two negatives stacked. Both escape options pre-closed. The only resolution = keep watching / save / follow.

## The psychology (4 stacked levers)

1. **Double-bind / closed escape** — Bateson (1972). Two contradicting impossibilities → mild cognitive dissonance → brain seeks resolution → only escape route is the reel itself.

2. **Loss aversion** — Kahneman & Tversky (1979). Humans feel losses ~2× more than gains. Stacking TWO losses = 4× emotional weight vs. positive framing.

3. **Self-recognition specificity** — the narrower the trap, the higher the self-recognition rate. "Quitting impossible AND staying impossible" describes a very specific person; that person feels SEEN. Save reflex fires hard.

4. **Pre-emptive objection neutralization** — most viewers reject obvious answers ("just quit", "just tough it out"). The trap names and dismisses both defaults in the hook itself, leaving only your idea standing.

## Why it earns saves >> likes

- Saves are private commitment ("I'll come back to this when I'm ready")
- Likes are public signal ("I want to be associated with this take")
- Negative trap = private pain. Viewers save instead of like.
- In 2026's algorithm where saves are ranking signal #3, this hook punches way above its like count.

## Structural template

```
[FRAME 1 — 0:00–0:01]
"If [thing they can't do]"

[FRAME 2 — 0:01–0:03]
"but [thing they also can't do]"

[FRAME 3 — 0:03–0:04]
"this is for you"

[BODY — 0:04 onward]
The non-obvious third path you're about to share.
```

## Variants

| Variant | Structure |
|---|---|
| **A. Pain stacking** | "If [pain A] but [pain B], this is for you" |
| **B. Capability stacking** | "If you can't [skill A] and don't have time to learn [skill B], this is for you" |
| **C. Time stacking** | "If you don't have 6 months to [thing] but can't wait until [thing], this is for you" |
| **D. Money stacking** | "If you can't afford to [pay X] but also can't afford to [not have X], this is for you" |
| **E. Identity stacking** | "If you're not [identity A] but also not [identity B], this is for you" |

## When NOT to use this hook

- On funnel-tagged slots (different tone register; don't mix sarcastic skits with emotional traps)
- On multi-character skits (the trap is talking-head-native; skits dilute it)
- When the second negative is a strawman (the trap collapses if viewers can mentally rebut it)
- More than 1× per cycle (high-stakes hook; overuse → audience fatigue)

## Voice-rule cross-check

- ✅ Curiosity-based (viewer leans in to learn the third path)
- ✅ Niche-narrow (the trap forces specific audience targeting)
- ✅ Not salesy (no "I made $X" framing)
- ⚠️ **Pain target check** — if the trap names client interactions / deliverables / unreliability as the pain, it violates the brand-image rule. Trap pains MUST target tools / niche-skill / dev-life / founder-life, never client work.

## Body structure (after the 4s hook)

```
[0:04–0:08] Re-state the trap in plain terms ("most people think you only have these 2 options")
[0:08–0:14] Reveal the third path (the actual tip / framework / move)
[0:14–0:20] Show OR explain the third path concretely (Layer 5 WHAT/HOW)
[0:20–0:24] Closer: "And that's why [punchy outcome]" — leave a tension beat
```

If the body is generic, viewers feel cheated → save rate plummets. The body MUST deliver a non-obvious third path.
