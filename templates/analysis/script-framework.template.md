# Script Framework — 5-Layer Reel Construction Rules (Template)

> Adapted from public reels in the creator-economy space. The `instagram-daily` skill validates every script against these 5 layers before outputting the brief.

Every reel script must satisfy ALL 5 layers below. Use this as a validator: if the script fails any layer, rewrite that piece before output.

---

## Layer 1 — IDEA

The reel's underlying premise must fit ONE of three buckets:

| Bucket | What it is | Example to fill in for your niche |
|---|---|---|
| **NOT-TO-DO** | A mistake to avoid; an anti-pattern | _your example_ |
| **TO-DO** | A specific action / habit / move worth taking | _your example_ |
| **2x TRUST** | Something that earns credibility — proof, behind-scenes, receipts, contrarian-but-correct take | _your example_ |

**If the script doesn't clearly land in one of these three, reject and rewrite the idea.**

> Customize for your niche: list 1-2 examples per bucket using your own past reels or topics.

> Voice-rule overlay: if your `voice-rules.md` forbids salesy "I made $X" framing on the personal account, restrict 2x-TRUST to credibility moves that AREN'T receipts/results-flexing.

---

## Layer 2 — VALUE

The value delivered must satisfy ALL three properties:

| Property | What it means | Failure mode |
|---|---|---|
| **NON-OBVIOUS** | The takeaway should NOT be something a viewer could've Googled in 10 seconds | Generic "use AI to be more productive" — fail |
| **HIGHLY TACTICAL** | Specific enough to act on within 5 minutes — name the tool, the prompt, the keystroke, the setting | Vague "use better prompts" — fail |
| **BINGE-WORTHY** | Hook + payoff structure that makes the viewer want a SECOND reel from you, not just this one | One-off explainer with no implied series → fail |

**If the value isn't ALL three, the reel will tank in saves/sends-per-reach.**

---

## Layer 3 — HOOK

Every hook follows the 3-beat structure:

```
COMMON BELIEF → CONTRADICT → CURIOUS
```

| Beat | What goes here | Example |
|---|---|---|
| **COMMON BELIEF** | A widely-held assumption you're about to puncture | "Everyone says X." |
| **CONTRADICT** | The reversal — your evidence/take that the belief is wrong | "But the truth is Y." |
| **CURIOUS** | The cliffhanger — what's the *how*, *what*, or *why* the viewer needs to watch to see | "Here's why." |

The first two beats fit in the **first 3 seconds**. The CURIOUS beat opens the body.

---

## Layer 4 — SCRIPT

Use "**BUT**" and "**SO**" as transition words to maintain tension. Optionally end with a "**TENSION**" closer.

| Transition | When to use |
|---|---|
| **"BUT"** | Pivot from setup → contradict / problem → unexpected |
| **"SO"** | Pivot from contradict → consequence / problem → solution |
| **TENSION (closer)** | Last beat: leave a question or implication open, don't fully resolve |

**Validator:** count the BUTs and SOs in the script. If zero, the script is flat — rewrite. More than 2 of each → over-stuffed, trim.

---

## Layer 5 — CONTENT (body structure)

The body of the reel — between hook and punchline — must explain at least 2 of these 3:

| Component | What it is | Length budget |
|---|---|---|
| **WHAT** | What is the thing? Concrete, specific. | 3–5s |
| **WHY** | Why does it work / matter / fix the problem? | 3–5s |
| **HOW** | How does the viewer apply it? Step or recipe. | 3–7s |

The strongest reels hit ALL THREE. Shortest reels skip one — usually WHY.

**Format-specific defaults:**

| Format | Body structure |
|---|---|
| Did-you-know (DY, 18–25s) | WHAT + HOW (skip WHY for tightness) |
| Green-screen reaction (GS, 12–18s) | WHY (the take IS the body) |
| Multi-char skit (SK, 15–22s) | Implicit WHAT + HOW (the skit dramatizes both); WHY in caption |
| Ranking (RK, 15–20s) | WHAT (items) + WHY (rationale) |
| Carousel (CR, 30s) | Full WHAT-WHY-HOW across slides |

---

## How `/instagram-daily` applies this framework

After writing the script and BEFORE writing the caption, the skill MUST:

1. Validate Layer 1 (IDEA bucket) — if not in NOT-TO-DO / TO-DO / 2x-TRUST, swap.
2. Validate Layer 2 (VALUE) — score non-obvious / tactical / binge. If any fail, sharpen.
3. Validate Layer 3 (HOOK) — read aloud; check belief→contradict→curious arc.
4. Validate Layer 4 (SCRIPT) — count BUT/SO. Need ≥1 of each.
5. Validate Layer 5 (CONTENT) — count WHAT/WHY/HOW. Need ≥2 of 3 for T2/T3, ≥1 of 3 for T1.

Output a **5-layer audit line** at the bottom of the brief so it's auditable in one glance.

---

## When this framework can be relaxed

- **T1 trend-driven reels** — speed over depth. Layer 5 can drop to 1 of 3.
- **Funnel-only skits** — punchline serves as value; binge-worthy is automatic if format is the proven funnel-winner clone.
- **Repurpose reels** — copy the framework from the original; don't re-validate.

For everything else, all 5 layers must pass.
