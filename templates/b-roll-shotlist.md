# B-Roll Shot List — Template

> Master shot list mapped to your 30-day calendar. Goal: film 80% of these in 2–3 batch days so daily reel production becomes editing + 1 fresh face-cam shot.

## Categories

- **C** = Costume / Character look (reusable)
- **F** = Face-cam clip (reaction beats — film once, reuse)
- **S** = Screen recording (tool/app demos)
- **E** = Environment / Setting (room, desk, café, etc.)
- **R** = Reaction shot (inserts)
- **O** = Overlay / on-screen text element (graphic templates)
