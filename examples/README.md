# Examples

A real working example to reference while filling in your own templates.

## `purvansh-parmar-AI-dev-humor.md`

A condensed example based on a real account: AI/dev humor in Hinglish, ~389 followers at the start of the cycle, multi-character skit format, business funnel to a separate handle for AI agent prototyping services.

This shows what a *good* fill of `creator-profile.md` and `voice-rules.md` looks like — specific, opinionated, grounded in actual data from one cycle of posting.

The full set of files (calendar, hooks library, b-roll list, baseline analysis) for this example are not included to keep the repo light, but the patterns translate. Read this as inspiration; don't copy it — your niche won't match.
